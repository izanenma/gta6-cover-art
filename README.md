Offline browser app that turns a photo and a caption into GTA 6-style cover art

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Pick a photo for each panel, choose a layout (4-panel grid, hero + 3, or full-bleed) and a neon-sunset grade (Sunset, Neon Night, Teal Heat), type the title and subtitle, nudge each panel's crop into place, and export the cover as a PNG in 1080 × 1080, 1080 × 1350, or 1920 × 1080. Photos never leave the machine; the Anton and Pacifico fonts are vendored under the SIL Open Font License in app/fonts.
